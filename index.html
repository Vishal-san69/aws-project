Project Executive Summary

This project implements an automated, production-ready continuous integration and continuous deployment (CI/CD) workflow on Amazon Web Services. Every push to the main branch of the GitHub repository automatically triggers AWS CodePipeline, passing through security verification before updating live assets on Amazon S3.
